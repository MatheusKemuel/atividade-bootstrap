Saborê Restaurante

Projeto de site responsivo para um restaurante usando Bootstrap 5.
Fiz um site para um restaurante onde conta com o cardápio do restaurante, preços dos pratos, formulários de contato e cadastro, um dashboard com informações como métricas de faturamento, pratos mais vendidos, tempo médio de preparo, etc.


1. Páginas do projeto

    Início (index.html): apresentação do restaurante, cardápio com 12 pratos, tabela de preços e formulário de contato.

    Cadastro (cadastro.html): formulário para preenchimento de nome, e-mail e senha, com validação de campos.

    Dashboard (dashboard.html): painel para apresentar informações e métricas do restaurante.

2. Classes Bootstrap utilizadas

    Layout: container, container-fluid, row, col-12, col-md-6, col-lg-3.

    Espaçamento: m-4, my-5, mb-4, p-2, py-5, gap-4.

    Flexbox: d-flex, flex-column, flex-wrap, align-items-center, justify-content-center, justify-content-between.

    Componentes: navbar, navbar-brand, nav-link, card, badge, btn, table, form-control, input-group.

    Responsividade e aparência: d-none, d-md-table-cell, text-center, fw-bold, rounded-5, shadow, h-100.

3. CSS próprio

    O arquivo style.css foi utilizado para personalizar cores, tipografia, imagens, botões e aparência dos componentes.

    Também foi necessário criar CSS próprio para o menu responsivo com checkbox, pois a navegação foi implementada sem JavaScript, além de  estilizar o modal de detalhes dos pratos e elementos específicos do layout.

4. Principais dificuldades

    Adaptar o layout para diferentes tamanhos de tela.

    Combinar as classes Bootstrap com o CSS personalizado.

    Criar um menu responsivo sem utilizar JavaScript.
